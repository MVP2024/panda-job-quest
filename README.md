# 🐼 PandaJobQuest

## 📋 Описание проекта

PandaJobQuest - это мощный инструмент для поиска и анализа вакансий, 
который помогает пользователям эффективно находить работу мечты.

## ✨ Возможности

- 🔍 Поиск вакансий по ключевым словам
- 💰 Сортировка вакансий по зарплате
- 📦 Сохранение найденных вакансий в локальное хранилище
- 🔬 Фильтрация вакансий по различным критериям
- 🌐 Работа с API HeadHunter
- 📊 Гибкий поиск и анализ вакансий

## 🚀 Установка

### Требования

- Python 3.10+
- Poetry
- Зависимости:
- requests
- python-dotenv

### Шаги установки

1. Клонируйте репозиторий:
    ```
    git clone https://github.com/yourusername/PandaJobQuest.git
    cd PandaJobQuest
    ```
   
2. Установите зависимости:
    ```
    poetry install
    ```
   
3. Настройте переменные окружения:
- Создайте файл `.env` в корневой директории проекта
- Добавьте необходимые ключи для HeadHunter API:
    ```
    dotenv
    # Ключи для аутентификации в HeadHunter API
    HH_CLIENT_ID=ваш_client_id
    HH_CLIENT_SECRET=ваш_client_secret
          
    # Опциональные параметры
    HH_USER_AGENT=PandaJobQuest/1.0
    ```

### Получение ключей API

1. Зарегистрируйтесь на [портале разработчиков HeadHunter](https://dev.hh.ru/)
2. Создайте приложение
3. Получите `Client ID` и `Client Secret`
4. Скопируйте полученные ключи в файл `.env`

⚠️ **Важно**: Никогда не публикуйте ваши приватные ключи в открытых репозиториях!

### Использование API

- Если приватные ключи не указаны, проект автоматически переключится на публичный API HeadHunter
- Публичный API имеет ограничения на количество запросов и доступных данных
- Для полного функционала рекомендуется зарегистрировать приложение и получить клиентские ключи

### Особенности работы с API

- 🔓 Автоматическое определение доступного API
- 🔄 Резервирование между приватным и публичным эндпоинтами
- 🛡️ Безопасная обработка отсутствия ключей
